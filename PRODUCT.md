# Product

## Register

product

## Users

Digi Tools is for makers and developers who want a focused place to assemble
prompts, structured notes, and small configuration artifacts without opening a
new script or hand-writing every file.

## Product Purpose

Digi Tools is a local-first browser toolbox. Each tool helps the user shape a
small artifact, inspect the result, and export it to their own machine. The
first tool is a Prompt Builder for ChatGPT, Claude, and other language models.

Success means a user can move from a rough idea to a useful, portable prompt in
one short session. The product does not require an account, database, or cloud
workspace.

## Brand Personality

Calm, precise, capable. The interface should feel like a compact workbench:
dense enough to be useful, quiet enough to stay out of the task, and explicit
about what will be exported.

## Anti-references

- Generic AI SaaS landing pages with purple gradients and oversized claims
- Decorative glass, parallax, marquees, site-wide 3D tilt, or cinematic reveals
- Empty dashboards filled with interchangeable metric cards
- Cloud-first product patterns such as accounts, teams, billing, and sync
- Copy that inflates a small utility into a life-changing platform

## Design Principles

1. Put the working artifact in view while the user builds it.
2. Prefer familiar controls and plain labels over invented interaction patterns.
3. Keep data local and make export behavior obvious.
4. Use density to support the task, not to make the interface look technical.
5. Add tools through a shared registry so navigation stays consistent.

## Accessibility & Inclusion

Target WCAG 2.2 AA for color contrast, keyboard access, focus visibility, form
labels, and responsive behavior. Respect the operating system reduced-motion
preference. Do not rely on color alone to communicate selected or error states.
