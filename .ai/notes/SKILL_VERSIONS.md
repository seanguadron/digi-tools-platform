## Review Notes

- Every installed directory contains a `SKILL.md`.
- `impeccable` and `web-design-guidelines` were reported as medium risk by one
  or more CLI scanners; their instructions and bundled files were reviewed.
- `web-design-guidelines` fetches its Vercel rule source at invocation time.
- AccessLint `scan` and `diff` download `@latest` CLI packages when invoked.
- AccessLint `diff` uses `git stash` and may temporarily switch branches. Root
  `AGENTS.md` requires explicit approval before that workflow runs.
- `webapp-testing` includes a server helper that executes the supplied local
  server command with shell semantics. Use only project-defined commands.
- Taste skills may suggest npm packages and hosted placeholder assets. Those
  remain task-specific dependencies and are not installed by this setup.
- GSAP skills may suggest `gsap` and `@gsap/react`; those runtime packages are
  not installed until a project task requires them.
